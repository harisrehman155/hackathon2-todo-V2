# Phase I Criteria (Detailed)

## Objective
Deliver an in-memory Python console todo application using strict SDD workflow.

## Required feature scope

- Add task
- View task list
- Update task
- Delete task
- Mark task complete/incomplete

## Mandatory gates

1. Specification gate
- `specs/<feature>/spec.md` exists and is complete.
- User stories and acceptance scenarios are testable.

2. Plan gate
- `specs/<feature>/plan.md` exists.
- Constitution checks are explicit and pass.

3. Tasks gate
- `specs/<feature>/tasks.md` exists.
- Tasks map to user stories and include validation tasks.

4. TDD gate
- Python tests use `pytest`.
- Red-Green-Refactor evidence exists.

5. Delivery evidence gate
- Source code for Phase I is present.
- Demo evidence and docs are updated for phase submission.

## Done criteria

Phase I is complete only when all gates pass and scope is fully demonstrated.

## Completion Contract

When all gates pass, the workflow returns:

1. `Phase 1 completion status: PASS`
2. `Choose next action:`
- `A) Test workflow yourself now (recommended first)`
- `B) Proceed to Phase 2 transition prep`
