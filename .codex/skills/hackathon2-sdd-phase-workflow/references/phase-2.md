# Phase II Criteria (Scaffold)

## Objective
Evolve Phase I into a full-stack web todo app with persistent storage.

## Expected scope scaffold

- RESTful task operations for authenticated users
- Persistent data storage
- Responsive frontend workflow
- User authentication and user data isolation

## Activation rule

Activate detailed criteria when Phase I is complete and phase branch transitions to `phase2`.

## Minimal gates

- Do not start implementation before Phase I done criteria.
- Keep SDD order: Specify -> Plan -> Tasks -> Implement.
- Require test and evidence mappings before merge.
